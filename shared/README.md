# 共享代码

- Contracts：插件接口、编辑与同步协议、结果及展示模型。
- Core：插件目录加载、依赖验证、比较模块调度。
- Cli：两个发行版共用的跨平台命令行宿主。
- plugins：Myers、Patience、文件/目录比较、编辑/合并、同步/备份/恢复、格式化和 UI 无关的左右对齐数据。

这里不应引用 WPF、Avalonia、Windows 注册表或某一桌面的文件选择器。操作系统差异若只涉及路径和文件语义，在共享实现中集中处理；平台外壳集成放在对应宿主目录。新功能优先扩展共享契约/插件，各宿主负责交互适配。

插件的发布布局仍是宿主旁的 `plugins`，与源码的 `shared/plugins` 是不同概念。单独构建解决方案不会自动部署插件；请使用根目录或 cross-platform 中的构建脚本。
